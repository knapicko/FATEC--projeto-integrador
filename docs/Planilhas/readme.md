# Planilhas do Projeto

Esta pasta centraliza os documentos de apoio em formato tabular utilizados no controle, planejamento e métricas da Conserta Já.

## Objetivo

Manter o registro organizado de dados analíticos que dão suporte à gestão do projeto e à tomada de decisão. 

## Conteúdo

Dependendo da fase atual de desenvolvimento, os artefatos desta pasta podem incluir:
* Cronogramas e estimativas de esforço de desenvolvimento.
* Levantamento de requisitos tabulados e análise de viabilidade.
* Matrizes de rastreabilidade, controle de riscos ou planilhas de custos atreladas ao uso de nuvem (Google Cloud) e APIs externas.
