# Documento de Visão

Esta pasta contém o artefato central de concepção e planejamento da plataforma Conserta Já.

## Objetivo

O Documento de Visão tem o propósito de fornecer um alinhamento de alto nível sobre o produto para toda a equipe e interessados. Ele define o problema que a aplicação resolve e detalha as necessidades dos usuários, com foco especial no público de prestadores de serviços de manutenção (como paneleiros, afiadores e técnicos).

Nesta seção, estão consolidadas informações sobre:
* Objetivos do projeto guiados pela metodologia SMART.
* Definição do público-alvo, perfis de usuário e personas.
* Escopo e limites iniciais do sistema.
* Restrições e premissas do modelo de negócio.
