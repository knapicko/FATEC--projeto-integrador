# Imagens do Projeto

Esta pasta atua como o repositório central de todos os recursos visuais vinculados à documentação e apresentação da plataforma Conserta Já.

## Conteúdo

Os arquivos armazenados neste diretório devem manter um formato otimizado e padrão de nomenclatura claro. Aqui podem ser encontrados:

* Capturas de tela (screenshots) demonstrando o aplicativo em funcionamento.
* Exportações estáticas de protótipos e interfaces (UI/UX).
* Elementos gráficos auxiliares utilizados nos arquivos de documentação, Readmes e apresentações do projeto.
