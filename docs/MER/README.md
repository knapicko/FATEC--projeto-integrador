# Modelo Entidade-Relacionamento (MER)

Esta pasta concentra os diagramas e modelagens do banco de dados relacional utilizado na plataforma Conserta Já.

## Objetivo

Os artefatos aqui presentes garantem o registro oficial da estruturação de dados do sistema, implementada via Supabase. O objetivo é manter uma fonte única de verdade para a equipe de banco de dados e backend.

## Conteúdo

* Diagramas MER / DER descrevendo a modelagem lógica e física.
* Definição de chaves primárias, estrangeiras e tipos de dados.
* Estruturação e justificativa das tabelas associativas, essenciais para o correto mapeamento e integração dos prestadores de serviço, clientes e catálogos de atendimento.
